# Market Guru — мини-приложения

Страницы мини-приложений для Telegram-бота @Market_Guru_Uz_Bot (GitHub Pages).

- `funnel.html` — 🧮 калькулятор воронки продаж: сколько заказов и денег даст +1/+2/+3% на открытиях, корзине или заказе.

Всё считается прямо в телефоне. Данные никуда не уходят, пока человек сам не нажмёт «Отправить в чат».
В этом репозитории нет ключей и данных — только страницы.

Исходник страницы — в закрытом репозитории бота (`webapp/funnel.html`); сюда копируется готовая версия.
